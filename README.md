# Retail Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project analyzes retail sales data using Microsoft Power BI to understand sales performance, profitability, and regional trends.

## 🎯 Objectives

- Analyze Total Sales and Total Profit.
- Calculate Total Orders and Profit Margin.
- Track monthly sales trends.
- Compare sales by product category and product.
- Analyze profit across regions.
- Explore data using interactive slicers.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📊 Dashboard Features

1. KPI Cards: Total Sales, Total Profit, Total Orders, Profit Margin %.
2. Monthly Sales Trend: Line Chart.
3. Category-wise Sales: Bar Chart.
4. Region-wise Profit: Bar Chart.
5. Product-wise Sales: Bar Chart.
6. Interactive Filters: Date, Region, Category, Segment.

## 📁 Project Structure

- `Retail_Sales_Analytics.pbix` — Power BI report.
- `data/` — Cleaned dataset, if included.
- `images/dashboard.png` — Dashboard screenshot.
- `README.md` — Project documentation.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If required, update the dataset path in Power Query.
4. Refresh the data and explore the interactive dashboard.

## 📈 Key Learnings

- Data cleaning and transformation.
- Creating DAX measures.
- Building interactive dashboards.
- Analyzing sales and profitability.
